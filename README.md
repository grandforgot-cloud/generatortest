# TestAI — Node.js + SQL

Это версия сайта без PHP. HTML/CSS/JS остаётся в папке `public`, а Node.js связывает сайт с MySQL через API.

## 1. Создай базу
Открой MySQL/phpMyAdmin и импортируй файл:

```sql
database.sql
```

Он создаст базу `testai_db` и таблицы:
- `users` — ученики и преподаватели;
- `tests` — опубликованные тесты;
- `questions` — вопросы;
- `options` — варианты ответов;
- `results` — результаты учеников.

## 2. Настрой подключение
Скопируй файл `.env.example` и переименуй его в `.env`.

Пример:

```env
PORT=3000
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=
DB_NAME=testai_db
JWT_SECRET=change_this_secret_key
```

Если у MySQL есть пароль, впиши его в `DB_PASSWORD`.

## 3. Установи зависимости
В папке проекта выполни:

```bash
npm install
```

## 4. Запусти сайт
```bash
npm start
```

Открой в браузере:

```text
http://localhost:3000
```

## Что уже подключено
- Регистрация ученика и преподавателя сохраняется в SQL.
- Вход работает через Node.js API.
- Преподаватель может публиковать тесты в базу.
- Ученик видит открытые тесты из базы.
- Результаты учеников сохраняются в SQL.
- Преподаватель видит результаты из базы.

## Важно
API-ключ Anthropic в этом варианте пока хранится в браузере, как и в исходном сайте. Для учебного проекта это нормально, но для настоящего сайта генерацию ИИ лучше тоже вынести на Node.js сервер.
